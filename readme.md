# BTS 4-Cut Photobooth 💜

A zero-build Korean Life4Cuts / Photoism style web photobooth built with HTML5, CSS3, and Vanilla JavaScript.

## 1. Adding Your Transparent BTS PNG Cutouts
Create the following subfolders inside `assets/` and drop up to 4 transparent `.png` poses per folder:

- `assets/rm/pose1.png` ... `pose4.png`
- `assets/jin/pose1.png` ... `pose4.png`
- `assets/suga/pose1.png` ... `pose4.png`
- `assets/jhope/pose1.png` ... `pose4.png`
- `assets/jimin/pose1.png` ... `pose4.png`
- `assets/v/pose1.png` ... `pose4.png`
- `assets/jungkook/pose1.png` ... `pose4.png`
- `assets/ot7/pose1.png` ... `pose4.png`

> **Tip:** Transparent PNGs cropped from the waist or chest up work best so they align naturally beside you in the camera frame. If any file is missing, the app automatically displays a styled placeholder badge so nothing breaks.

## 2. Running Locally in VS Code
1. Open the `bts-photobooth` folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and select **Open with Live Server**.

## 3. Sharing via HTTPS Link (Required for Mobile Cameras)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop your entire `bts-photobooth` folder onto the page.
3. Copy the generated `https://...netlify.app` link and send it directly to her phone or laptop.
